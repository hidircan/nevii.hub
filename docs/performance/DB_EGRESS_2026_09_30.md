## 5. Hâlâ tam `readData()` kullanan önemli yollar (öncelik sırası)

`readData()` çağrı noktası (store dosyaları hariç) 273 → 175; `readScopedData` 36 → 10.
1. **Panel özeti** — ödeme toplamları, bugünkü dersler, ay hakediş özeti, kurulum ilerlemesi: finansal toplamlar SQL
   toplamına ya da (tüm ödemeler + ay/gün ders penceresi) dilimine taşınmalı; ayrı, finans testli tur.
2. **Hakedişler** + öğretmen hakediş/portal sayfaları — dönem penceresi yeterli görünüyor ama kayıtlı hakediş
   `lineSnapshot`/drift hesabı ayrıca doğrulanmalı (kayıtlı ↔ canlı ayrımı).
3. **Telafi** — `validateLessonSlot` öğretmen/oda gün penceresi ister (readLessonScope deseni).
4. **Öğretmenler** — skor yalnız son 30 günün dersini okur ama kart TÜM ZAMANLARIN ders sayısını gösterir;
   pencereye çevirmek sayıyı sessizce değiştirir → önce `groupBy` sayımına geçirilmeli.
5. Öğretmen detay sekmeleri (`/panel/ogretmenler/[id]/*`), Ders Düzeltme, Yoklama Raporu, Denetim Kaydı, makbuz/döküm,
   dışa aktarma, `ProgramLiveRefresh`'li öğretmen ana sayfası (`/ogretmen`).
6. Yazma sonrası tam okuma: store-db mutasyonlarının çoğu `return readData()` (AppData sözleşmesi) — dönüş tipi
   daraltılmadan kalkmaz. `prisma.school.update` dönüşü de logoyu taşır (ayar değişikliği, seyrek).
7. Portal: duyuru aracı hâlâ tüm öğrenci listesini okur (~120 KB / portal yenilemesi); alıcı tek öğrenci/öğretmen.

## 6. Supabase panelinde karşılaştırma

- **Usage → Egress (Database)** günlük grafiği: dağıtım gününü (karışık gün) dışarıda bırakın; **önce** 2026-09-26 → 09-29,
  **sonra** dağıtımdan sonraki ilk tam 3–4 gün. Egress trafikle orantılıdır: UAT yoğunluğu farklı günleri doğrudan
  karşılaştırmayın; mümkünse Vercel istek sayısına bölün.
- Gerçek sorgu düzeyi karşılaştırma (salt okunur; dağıtım öncesi anlık görüntü 2026-09-30 12:38 UTC:
  School findFirst 13 974 çağrı · Payment include 13 662 çağrı / 10 040 798 satır · Lesson include 7 837 686 satır ·
  Student include 2 263 604 satır · kurum listesi üzerinden School 16 423 çağrı · bildirim listesi 3 166 çağrı / 329 162 satır):

```sql
select
  sum(calls) filter (where query like 'SELECT %"public"."School"."logoUrl"%') as school_rows_with_logo_calls,
  sum(calls) filter (where query like 'SELECT %FROM "public"."Payment" WHERE "public"."Payment"."schoolId" IN (%') as payment_include_calls,
  sum(rows)  filter (where query like 'SELECT %FROM "public"."Lesson" WHERE "public"."Lesson"."schoolId" IN (%') as lesson_include_rows,
  sum(rows)  filter (where query like 'SELECT %FROM "public"."Notification" WHERE (%targetUserId%ORDER BY%') as notification_rows
from pg_stat_statements where dbid = (select oid from pg_database where datname = current_database());
```
Aynı sorguyu birkaç gün sonra çalıştırıp anlık görüntüden farkı gün sayısına bölün (çağrı/gün, satır/gün).
